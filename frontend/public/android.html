STEP 1 OF 6

Troubleshooting · every known snag

If something looks wrong, it's one of these five.

Tap "Show me" to load the exact screen on the phone above, with its fix.

EXPECTED SCREEN

"Unsafe app blocked" (Play Protect)

VantageLife isn't in the Play Store yet, so Google shows its standard warning for every private beta. Nothing is wrong with the app.
FIXTap More details, then Install anyway. Tapping "Got it" cancels the install.
FIRST-TIME SETTING

Phone won't allow the install

First sideload ever? Android requires a one-time permission for the browser you downloaded with ("Install unknown apps").
FIXOn the settings screen that opens, flip Allow from this source for Chrome, go back, and the install continues.
ERROR

Build expired / link won't load

You tapped a link from an older email — each new build gets a new link and old ones stop working.
FIXOpen the newest "The new AO Premier agent app is here" email from betatest@hypervividstudios.com and use its Android button.
ERROR

Code page: "Invalid state parameter"

During Google sign-in the browser lands on a raw code page reading "invalid_request … Invalid state parameter." This was a launch-week platform bug — it has been fixed for all affected agents.
FIXClose the sheet, return to VantageLife, and tap Sign in with Google again. Still stuck? Email betatest@hypervividstudios.com.
ERROR

"Account Pending" after sign-in

Two causes: you signed in with the wrong Google account, so the email doesn't match the roster — or you don't have an active profile in the app yet.
FIXTap Sign Out, then Sign in with Google using the email your upline has on file. No profile yet? Send the onboarding email below.

Need to be added? One email gets you onboarded.

Write to betatest@hypervividstudios.com with exactly four things: your first and last name, the email address to invite, your phone number, and your upline. You'll get a fresh TestFlight invitation at that address.
